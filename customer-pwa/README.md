# ZoolFast Customer PWA

هيكل أولي لتطبيق العميل داخل نفس مستودع ZoolFast. هذه الدفعة لا تحتوي صفحات كاملة ولا APK.

## ما تم تجهيزه

- PWA shell متجاوب للموبايل واتجاه RTL.
- الهوية الأساسية: برتقالي `#FF7A00` وأبيض.
- manifest وService Worker للتثبيت على الشاشة الرئيسية.
- طبقة Supabase قراءة قابلة لإعادة الاستخدام في `supabase-data.js`.
- إعداد المشروع في `supabase-config.js` باستخدام Publishable Key فقط.
- صورة المؤسس الأصلية محفوظة كما هي في `assets/founder_card.jpg` للاستخدام في صفحة «من نحن» بالدفعة التالية.

## ملاحظة الاتصال

تم فحص رابط REST أثناء الدفعة الأولى، وأعاد Supabase حالة `401 Unauthorized`. لذلك لم يتم افتراض أسماء جداول أو إدخال بيانات وهمية. يلزم لاحقاً تأكيد المفتاح العام/إعداد RLS قبل بناء مصادر المطاعم والمتاجر والصيدليات.
