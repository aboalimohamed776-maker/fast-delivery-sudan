# ZoolFast Admin Web

لوحة تحكم تجريبية responsive لعمليات ZoolFast داخل بورتسودان. هذه النسخة لا تستخدم Firebase أو GitHub Secrets؛ البيانات محلية داخل `app.js` ومهيأة للربط لاحقاً.

## التشغيل

من مجلد `admin-web`:

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## الموجود في النسخة

- Dashboard بملخص الطلبات والمبيعات والكباتن ورسم مبيعات أسبوعي.
- 8 طلبات تجريبية، مع الطلب `ZF-10482` ومثال فرخة كاملة مشوية: `25,000 + 4,000 = 29,000 SDG`.
- طلبات حية مع بحث وفلترة وتنبيه طلب جديد وتحويل الطلب خلال 3 ثوانٍ.
- خريطة SVG تجريبية لمدينة بورتسودان فقط، دون أسماء أحياء، بها 5 كباتن تتحرك كل 5 ثوانٍ، 4 مطاعم، زبون، ومسار طلب.
- إدارة الكباتن وأكواد الاشتراك الأسبوعية والشهرية.
- إدارة 4 مطاعم تجريبية وقائمة المينيو وإضافة وجبات.
- إعدادات التوصيل والدعم والتنبيهات.

هذه الواجهة التجريبية ليست نظام صلاحيات إنتاجياً؛ عند الربط الحقيقي يجب نقل التحقق إلى Firebase Auth/Firestore Rules وعدم الاعتماد على كود الدخول الموجود في المتصفح.
